# Heart Disease Prediction

## Objective
Predict the presence of heart disease using machine learning 
classification models trained on the Heart Disease dataset.

## Dataset
Heart Disease Dataset
- 303 samples
- 14 features including age, cholesterol, blood pressure
- Target: 0 = No Disease, 1 = Disease

## Models Used
- Logistic Regression
- Random Forest Classifier

## Evaluation Metrics
- Accuracy
- F1 Score
- Confusion Matrix
- Classification Report

## Key Insights
- Chest pain type and max heart rate are strong predictors
- Random Forest outperforms Logistic Regression
- Feature scaling improves model performance

## Tools Used
Python, Pandas, NumPy, Matplotlib, Seaborn, Scikit-learn
